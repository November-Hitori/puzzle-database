# 日历题目改进验证

本次修改取消中立投票并一次性清理对应历史评价，新增独立留言及剧透展开、创建者编辑和可选清除评价，复用规则搜索下拉框选择原型，并减少审计与投票时的全量读取和页面重建。后续增加三种独立题目链接、四个日历区域、三人 Penpa 制图审计、正式日期分配和版本化错误忽略。规范正文来自用户补充的 `docs/penpa.md`，已纳入项目发行目录。

验证使用临时 SQLite、虚构账号及会话；未访问应用现有数据库或生产服务。

- Node 测试：32 项通过，1 项私有工作簿测试因未提供载荷按原设置跳过。
- Python 工作簿测试：7 项通过。
- JavaScript 语法检查及 `git diff --check`：通过。
- 新增工作流接口与迁移检查：仅提供 Penpa 解题或 puzz.link 的投稿、链接模式与题目载荷校验、三票通知、质量分区、三个不同成员制图审计及重复投票、日期占用及并发冲突、闰日和非法日期、取消分配、支持撤回或否决释放档期、版本失效、错误忽略与恢复、旧链接/ID/完成时间/评价保留，以及迁移幂等。
- DOM 交互检查：平均难度和留言默认隐藏及主动展开；留言安全转义、失败保留草稿、成功后刷新；创建者编辑默认保留评价、显式清除后重新评价；规则原型搜索和键盘选择；审计延迟、重复点击、局部更新和失败恢复；投票、否决、重新进入新轮次时保留原解题 iframe；退出后丢弃迟到响应；三种上传链接、制图规范全文、三人制图审计与日期分配、闰年二月月视图及空日期、取消分配后空格恢复、规则与题目错误忽略标识及恢复；局部更新后的编辑按钮使用最新版本；规则级忽略恢复不覆盖题目自己的忽略；规范正文更新后先加载最新版本再允许审核。

真实桌面浏览器验收已完成：Chromium 141.0.7390.37，1440×1000 桌面视口，真实 HTTP 服务和浏览器会话。此前的沙箱限制曾阻止测试；本轮提权已可用，缺少的系统库从 Ubuntu 官方包下载、校验 SHA-512 后仅解压到 `/tmp`。原生 `npm test` 随后完整运行，32 项通过、1 项跳过，不再依赖进程内 HTTP 传输。

浏览器验收覆盖真实注册、密码登录、HttpOnly/SameSite 会话、未登录访问边界、剧透展开、留言转义和提交失败保留草稿、延迟投票与重复点击、规则局部更新、原型搜索键盘选择、错误忽略与恢复、仅 puzz.link 的上传、三票补链接通知、链接版本编辑、三人制图审计、闰年二月、取消分配、否决后留言、重新进入和退出后的迟到响应隔离。未捕获页面异常为零。检查还发现退出请求未完成时可输入的登录字段会被后续刷新清空；现已在等待阶段禁用输入，并用延迟退出请求重跑验证。

外部 Penpa / puzz.link 页面由测试 HTML 替代，以避免将测试数据发送给第三方；因此这次验证的是本应用界面、链接与 iframe 生命周期，不代表第三方解题平台可用性。未访问生产服务，也未增加应用依赖。测试驱动由 [tools/browser-check.mjs](../tools/browser-check.mjs) 和 `npm run test:browser` 提供；安装及运行参数见 README。

性能实验使用隔离数据中的 600 条规则、18,000 条审计历史事件。旧审计路径包含写入后返回整个目录及额外一次目录请求，合计约 386 毫秒，JSON 总量约 6.5 MB；新路径只提交并返回对应规则，约 5 毫秒、6 KB。数字为本机模拟结果，不代表生产延迟。前端另外避免重建整个规则目录，以及题目投票后的解题 iframe。

在可运行服务的环境中，常规验证命令仍为 `npm test`，Python 验证为 `python3 -m unittest discover -s tests -p 'test_*.py'`。真实桌面浏览器检查已通过；发布前仍需按贡献工作流完成发行包预检及独立验收。
