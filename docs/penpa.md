Penpa+制图标准 / 小技巧 文件格式： 题目和答案必须分别在相应的图层绘制，确保在Problem模式下，Visibility OFF和ON分别能看到题面/解答 Source需要添加对应的puzz链接 小技巧： 如果Load之后提示penpa+不支持导入该题型，可以试图寻找相似排版的题型，切换一下题型名看看能不能导入，导入成功后在Share界面把题型改回来即可。以及在New Grid / Update界面修改一下虚线/盘面外边框/格点等 举例：(Hinge / Heyawake, All or Nothing / Norinori / Double Back, Wittigen / Slitherlink) 网格： 除以下少数情况外，尽量使用虚线网格： 数独、数和等特别经典的填数，可以按习惯选择使用实线格 类Slitherlink、Free line题，使用点阵格 正交连接题（数桥，Shirokuro-link，Coffee Milk），使用无网格 颜色（区分的主要目的是方便后续的代码调色）： 题目： 涂黑使用BL/LG （BL用于常见涂黑，LG可用于yajilin、dbchoco等） 答案： 涂黑使用GR 画线、数字使用绿色 图形： 圆： 无数字圆题型： 对于可能出现在边角的圆，根据题型酌情选择： 如果可能相邻，使用粗线XS号圆（No Three） 如果不可能相邻，使用粗线S号圆（Tentaisho） 对于在格内的黑白圆，使用粗线M号圆（Masyu、Binairo、Statue Park） 有数字圆题型： 对于可能出现在边角或者线可能经过的圆，使用粗线M号圆+L号数字（Balance Loop、Slant） 对于在格内的数字圆，根据美观性使用粗线L号圆+Normal号数字或者带圈Normal号数字均可 箭头： 尽量以原题型习惯为准 对于复杂题型，则以风格的统一性和美观性为准
