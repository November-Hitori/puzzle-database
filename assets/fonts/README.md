# 阿里巴巴普惠体网页字体

网站自托管[阿里巴巴普惠体官网](https://www.alibabafonts.com/)提供的 3.0 版 WOFF2，所有字体二进制保持官方原样，不依赖外部字体服务。

正文、标题、数字和表单控件共用 `Alibaba PuHuiTi`。Regular 对应 400，Medium 对应 500/600，Bold 对应 700；各字重使用官网已经提供的六个 `unicode-range` 分片，让浏览器只下载页面文字需要的部分。无需预加载全部字重或完整字体。

官网分片覆盖 9,938 个字符。第二字体族 `Alibaba PuHuiTi Full` 使用官方完整 Regular，并通过 CSS 限定在分片缺少的字符范围，保留完整字体支持的 29,197 个字符；例如“䶮”“㐀”“龘”会按需加载该文件。CSS 回退范围排除空格、不换行空格、全角空格和两个控制字符，它们交由系统处理，避免空白引起完整字体提前下载。罕见字的粗体由浏览器合成，超出完整字体字符集的符号继续使用系统字体。外链箭头使用 SVG，避免装饰符号触发完整字体下载。

19 个字体文件合计 9,601,732 字节（约 9.16 MiB），其中常用字分片为 4,344,992 字节。文件名含内容哈希，服务器只公开清单里的字体文件及 `puhuiti.css`；字体文件长期缓存，HTML 和 CSS 不使用不可变缓存。

每个文件的官方 URL、原始 CSS 地址、大小、字重和 SHA-256 保存在 `manifest.json`。`puhuiti.css` 使用官方分片的原始 Unicode 范围；完整文件的 CSS 回退范围来自其字符表减去分片已有字符。改动字节或字体版本时必须生成新的哈希文件名，并同步清单、CSS 和验收。

字体使用条件见官网的[法律声明](https://www.yuque.com/yiguang-wkqc2/puhuiti/nus9wiinq4aeiegy)和[常见问题](https://www.yuque.com/yiguang-wkqc2/puhuiti/ti3pl9oxmyfpb87a)；本目录保留了 `LEGAL-NOTICE-3.0.txt`。本项目使用官方原生网页字体和原生分片，不自行修改、转换或拆分字体文件。
