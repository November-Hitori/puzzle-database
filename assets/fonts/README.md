# 阿里巴巴普惠体网页字体

网站使用阿里巴巴普惠体 1.0。字体源自[阿里巴巴普惠体官网](https://www.alibabafonts.com/)提供的 WOFF2 文件，文件保持原样，包含原有版权信息与完整字符集。

本机 Windows 字体目录已有对应的 `阿里巴巴普惠体 R.ttf`、`阿里巴巴普惠体 M.ttf`、`阿里巴巴普惠体 B.ttf`，版本均为 1.00。部署使用官网的网页格式文件。

字体的法律声明和使用说明以官网为准：[法律声明](https://www.yuque.com/yiguang-wkqc2/hgpff0/nus9wiinq4aeiegy)、[常见问题](https://www.yuque.com/yiguang-wkqc2/hgpff0/ti3pl9oxmyfpb87a)。
